# Многомерная модель оценки вовлечённости обучающихся по данным цифрового следа

Код к статье 2 диссертационного исследования
«Модели и методы адаптивной геймификации образовательной платформы на основе обучения с подкреплением для управления вовлечённостью обучающихся».

**Что делает репозиторий:** по логам OULAD строит недельный индекс вовлечённости
E(t) = w_B·B(t) + w_C·C(t) (поведенческая и когнитивная компоненты, опционально эмоциональная),
проверяет его валидность, выделяет типы траекторий (k-means, GMM) и скрытые состояния (HMM),
прогнозирует падение вовлечённости (логистическая регрессия, градиентный бустинг, LSTM)
и находит горизонт раннего предупреждения.
Функция E(t) и матрица переходов HMM дальше используются как вознаграждение и модель переходов в RL-части диссертации.

## Методика (кратко, для раздела «Методы»)

**Индикаторы** (неделя × студент, `engagement/features.py`):

| Компонента | Индикатор | Направление |
|---|---|---|
| B | клики, активные дни, число ресурсов, энтропия типов активности | + |
| B | недель с последней активности | − |
| C | доля сданных заданий (накопительно), средний балл, доля кликов quiz | + |
| C | среднее опоздание сдачи | − |

**Индекс** (`engagement/index.py`): процентильная нормализация внутри «курс × поток × неделя»
(индекс сравним между курсами разной нагрузки) → веса индикаторов → B(t), C(t) → E_raw(t) → EMA-сглаживание.
По умолчанию равные веса: на OULAD они дали наибольшую связь с итогом (ρ = 0.498 против 0.481 у энтропийных
и 0.483 у PCA, см. `index_ablation.csv`). Веса оцениваются только по обучающим потокам.
Индекс формативный, поэтому низкая α Кронбаха ожидаема; валидность обосновывается внешним критерием.

**Валидность:** α Кронбаха, ρ Спирмена между E и итогом (Withdrawn < Fail < Pass < Distinction), критерий Краскела–Уоллиса.

**Состояния** (`engagement/states.py`): k-means по траекториям E(0..19); число кластеров сравнивается по силуэту
и «локтю» BIC модели GMM, итоговое k = 4 задано по интерпретируемости (`clustering.k_final`).
Гауссовская HMM по (B, C) обучается только на обучающих потоках, число состояний по BIC, состояния упорядочены
по уровню вовлечённости. Для прогноза используются отфильтрованные вероятности состояний
P(s_t | данные до t) (прямой проход) — без заглядывания в будущее.

**Прогноз** (`engagement/predict.py`): для студентов, которые сейчас не в нижнем состоянии HMM,
y = 1, если в ближайшие h = 2 недели они перейдут в нижнее состояние или отчислятся.
Прежнее пороговое определение (падение E вдвое) сохранено для сравнения (`label_comparison.csv`):
на OULAD оно почти целиком сводится к отчислению. Базовая модель — марковский прогноз только
по матрице переходов HMM; модели машинного обучения сравниваются с ней.
Временное разбиение: обучение на потоках 2013B–2014B, тест на 2014J (без утечки будущего).
Метрики: ROC-AUC, PR-AUC, F1 (порог по валидации), AUC по неделям.
Раннее предупреждение — первая неделя, на которой AUC прогноза итога Withdrawn/Fail ≥ 0.80.

## Ограничения и расширения

- Эмоциональный компонент (DAiSEE / EngageNet) подключается через `data/processed/emotion.csv` и `index.emotional_weight`. Модель распознавания по видео в репозиторий не входит.
- Перенос на KDD Cup 2015 (XuetangX) требует адаптера логов к формату `features.py`. Это следующий шаг для проверки обобщаемости.
