# engagement-model

**Многомерная модель оценки и прогнозирования вовлечённости обучающихся по данным цифрового следа для адаптивной геймификации**

*A multidimensional model for assessing and forecasting learner engagement from digital trace data for adaptive gamification*

Репозиторий содержит код и результаты экспериментов к статье:

> Жүсіп Т.Н., Ламашева Ж.Б. Многомерная модель оценки и прогнозирования вовлечённости обучающихся по данным цифрового следа для адаптивной геймификации. Евразийский национальный университет им. Л.Н. Гумилёва, Астана, Казахстан. *(статья направлена в печать)*

## О проекте

По журналам действий и оценкам обучающихся строится недельный индекс вовлечённости E(t), состоящий из поведенческой (B) и когнитивной (C) компонент. По нему выделяются типы траекторий и скрытые состояния вовлечённости, а также прогнозируется спад вовлечённости на две недели вперёд. Модель предназначена для использования в качестве состояния и вознаграждения RL-агента адаптивной геймификации. Расчёты выполнены на реальных данных **OULAD** (Open University Learning Analytics Dataset).

Проводятся пять экспериментов:

| Эксперимент | Что проверяется |
|---|---|
| **E1** | Индекс вовлечённости E(t): 9 индикаторов, нормализация внутри курса и недели, связь с итогом курса, сравнение 6 схем нормализации и взвешивания |
| **E2** | Типы траекторий вовлечённости: k-средних и гауссова смесь, выбор числа кластеров по силуэту и BIC |
| **E3** | Скрытые состояния: гауссовская скрытая марковская модель (СММ), матрица переходов, прямой проход без заглядывания в будущее |
| **E4** | Прогноз спада вовлечённости на 2 недели: сравнение двух определений спада и 4 моделей (марковская базовая, логистическая регрессия, градиентный бустинг, LSTM) |
| **E5** | Раннее предупреждение: прогноз итога Withdrawn/Fail по данным до недели t |

## Основные результаты

- Индекс E(t) связан с итогом курса: **ρ Спирмена = 0,498** (p < 0,001); схемы взвешивания дают близкие значения (0,481–0,498).
- Выделены 4 типа траекторий; тип «низкая, снижается» (**22,7%** обучающихся) завершает курс неуспешно в **89%** случаев.
- СММ с 4 состояниями показывает, что в невовлечённость обучающиеся переходят **только** из состояния «активен, но с низкой результативностью» (**0,047** в неделю); из более высоких состояний вероятность такого перехода равна нулю.
- Градиентный бустинг прогнозирует спад вовлечённости с **ROC-AUC 0,925** и **PR-AUC 0,536** при доле положительного класса 7,2%, что по PR-AUC на **50%** выше марковской базовой модели; LSTM преимущества не даёт.
- Риск неуспешного завершения курса прогнозируется с ROC-AUC ≥ 0,80 начиная с **8-й недели**.

Полные результаты: [`outputs/hmm4/report.md`](outputs/hmm4/report.md) и [`outputs/hmm4/metrics.json`](outputs/hmm4/metrics.json).

## Структура репозитория

```
run_pipeline.py              основная программа (эксперименты E1–E5, для статьи)
config.yaml                  параметры эксперимента
engagement/
  data.py                    загрузка таблиц OULAD
  features.py                недельные поведенческие и когнитивные индикаторы
  index.py                   индекс E(t), веса, проверка валидности
  states.py                  кластеры траекторий, СММ, прямой проход
  predict.py                 прогноз спада, марковская базовая модель, LSTM, раннее предупреждение
  plots.py                   рисунки
scripts/make_synthetic_oulad.py   генератор синтетических данных в формате OULAD
tests/                       автотесты (pytest)
outputs/hmm4/                результаты для статьи: report.md, metrics.json, таблицы CSV, рисунки fig1–fig5
```

## Данные

Датасет OULAD **не входит** в репозиторий из-за размера (около 450 МБ). Его нужно скачать отдельно:

- официальная страница: https://analyse.kmi.open.ac.uk/open_dataset
- зеркало UCI: https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset
- лицензия: CC BY 4.0

Распакуйте CSV-файлы в папку `data/raw/oulad/`, чтобы получилось `data/raw/oulad/studentVle.csv`, `data/raw/oulad/studentAssessment.csv`, `data/raw/oulad/assessments.csv` и т. д. (всего 7 файлов).

## Установка и запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
# source .venv/bin/activate       # Linux / macOS
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
```

Запуск:

```bash
python run_pipeline.py --out outputs/hmm4   # полный эксперимент на данных OULAD (около 8 минут)
python run_pipeline.py --synthetic          # проверка на синтетических данных, без OULAD
python run_pipeline.py --no-lstm            # ускоренный режим без LSTM
python -m pytest -q                         # автотесты
```

Результаты сохраняются в папку, указанную в `--out` (по умолчанию `outputs/`).

## Ограничения

Использован один датасет британского дистанционного университета; перенос на казахстанские платформы требует проверки. Эмоциональная компонента вовлечённости не реализована: она подключается через файл `data/processed/emotion.csv` и параметр `index.emotional_weight` в `config.yaml`. Индекс относителен (процентиль среди однокурсников в ту же неделю), поэтому не отражает одновременное снижение активности всего потока.

## Дополнительные проверки

| Проверка | Как запустить | Результаты |
|---|---|---|
| Сравнение схем нормализации (процентиль, минимакс) и взвешивания (энтропийные, PCA, равные) | выполняется в основном прогоне | `index_ablation.csv` |
| Пороговое определение спада (E упала вдвое) против перехода в нижнее состояние СММ | выполняется в основном прогоне | `label_comparison.csv` |
| Устойчивость к числу скрытых состояний (5 вместо 4) — **вариант, приведённый в статье для сравнения** | в `config.yaml` задать `hmm.n_states_range: [2, 3, 4, 5]`, затем `python run_pipeline.py --out outputs/hmm5` | `outputs/hmm5/report.md`, `hmm_selection.csv`, `hmm_state_means.csv` |
| Выбор числа кластеров по «локтю» BIC вместо фиксированного k = 4 | в `config.yaml` задать `clustering.k_final: null` | `clusters_selection.csv`, `clusters_profiles.csv` |
